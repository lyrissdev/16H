IMPORTANT
Une PWA ne peut pas être installée correctement depuis un fichier local file://.
Le dossier doit être servi depuis une adresse HTTPS.

INSTALLATION IPHONE
1. Ouvrir l'URL de 16H dans Safari.
2. Partager.
3. Ajouter à l'écran d'accueil.
4. Ouvrir 16H depuis son icône.

INSTALLATION MAC
Avec Safari :
1. Ouvrir l'URL.
2. Fichier > Ajouter au Dock.

DONNEES
Cette version conserve le système actuel localStorage.
Les blocs restent donc enregistrés localement sur chaque appareil.
La synchronisation Mac/iPhone nécessitera une étape supplémentaire avec une base cloud.
